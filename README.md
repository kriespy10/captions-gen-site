Captions Gen website — https://captionsgen.com/

Static website hosted on GitHub Pages from the main branch. Edit index.html; images are in img/.

The homepage presents the public Windows plugin for Premiere Pro and After Effects. Its browser demo reflects the 1.1.10 design controls, retained in 1.1.11, and a prepared caption workflow. A fresh demo starts on Bold Impact. Switch between Premiere Pro and After Effects to try separate sample projects, generate prepared captions, edit words, apply a style and undo a sample change. The demo does not transcribe audio, read your media, download speech models or operate either Adobe application. Sample timing is estimated; the browser preview does not establish identical native rendering.

`caption-presets.mjs` contains the 18 built-ins and defaults verified against both public 1.1.10 packages. `caption-engine.mjs` adapts the released preview formulas, and `caption-grouping.mjs` copies the grouping implementation. `caption-sample.mjs` supplies the prepared captions and estimated word timings; `caption-workflow.mjs` connects their host-specific editing examples. `caption-preset-format.mjs` handles v4 preset files and exports the actual 101 language-picker options (Auto-detect plus 100 languages). Sync these sources when the released controls or designs change. The preview uses explicit web font fallbacks, including Montserrat Black for The Bold Font and Bangers for Komika Axis, and keeps the chosen text color on pill highlights.

The Customize tab has separate Caption text and Design cards. Caption text controls case, punctuation, word/character/duration limits and line count. Design groups follow the panel order: Text, Karaoke, Animation, Stroke, Shadow, Background. Letter spacing uses real pixels from 0 to 16. Group resets restore that part of the active preset. The website uses accessible buttons, labeled inputs and native color inputs in place of UXP widgets.

The Premiere Pro example offers caption editing and a manual Properties text-edit example; the After Effects example adds a Captions tab with search and whole-word find/replace, plus a manual Source Text example. Manual text changes expose Update animation. Saving through the caption editor updates the sample text and animation together. Optional transcript review lets visitors change the prepared lines before generation. Apply style and Undo affect only the sample project. Settings offers interactive model, searchable language and placement examples; Add example model assigns a menu example to Slovak without accessing folders or installing a model. Model and language choices do not change recognition quality or translate the prepared text.

Save preset opens the contextual Save as preset/Save as new, Update this preset, and Revert changes actions. Your presets are stored separately from the built-ins in browser local storage (up to 30); the tile menu can set a main preset, duplicate, rename, export or delete. Main presets are restored on reload. Export uses the plugin's v4 `.cgpreset` format including font metadata; Import accepts current v4 files and asks visitors to migrate older files in the plugin. Browser substitutes are disclosed while the imported font identity is retained for export until a different font is chosen. Existing browser saves migrate their earlier spacing scale once and persist v4 values. Sample captions, text edits, Undo history and example-model assignments remain in page memory and reset on reload or Reset demo; they are not saved with a design preset. Reset demo keeps saved presets and the main-preset preference.

The footer links directly to the free full Windows installer on GitHub Releases. Previews play on demand and stop at the end; rendering suspends offscreen and in background tabs, and reduced motion disables automatic replay.

Generate the guides with `python -B tools/genblog.py` from the repository root. The generator includes the shared analytics assets and preference controls on every guide.

News posts (one per release) live in `tools/news.py`, newest first. The same command builds `news/`, `news/index.html`, the RSS feed `news/feed.xml` and their sitemap entries.

Guide content lives in `tools/bodies.py`, `tools/bodies2.py`, `tools/bodies3.py` and `tools/aftereffects.py`. Premiere-specific tutorials retain their host-specific steps; After Effects has its own setup and first-caption guide. New guides need an explicit `published` date. Set an entry's `modified` date only when its article content changes; the generator preserves publication dates and uses modification dates in the page and sitemap. Update SITE_UPDATED in the generator for homepage changes, and GUIDE_INDEX_UPDATED for guide-index changes. Keep visible copy, metadata, pricing and checkout consistent.

Google Analytics uses measurement ID `G-PR571RC95P` in analytics.js. The Google tag loads only after opt-in, only on captionsgen.com and www.captionsgen.com. Installer links send `download_click` with page placement and a version when the URL identifies a particular asset; this measures clicks, not completed downloads. Legacy checkout click recognition remains for historical links. Visitors can revoke analytics using the footer control. Local previews do not send analytics.

Download buttons use `https://api.captionsgen.com/api/download/windows`, which counts download requests and redirects to the published full Setup asset in GitHub Releases, currently `v1.1.11/CaptionsGen-Setup-1.1.11.exe`. The full installer exceeds GitHub's Git-file size limit and must stay a Release asset. The update manifest's `full` link keeps the direct GitHub asset as a fallback; its smaller Update EXE is published under update/. Before changing the current version, upload and verify the release asset, then update `tools/product.py`, the Worker installer target and `update/version.json` together. Browser estimates use separate daily/calendar-month date markers; installations and opted-in sessions require the matching new plugin. See `worker/README.md` for coverage and rollout flags.

The existing private dashboard at https://api.captionsgen.com/funnel now includes Installer downloads, read through authenticated `/api/downloads`. It aggregates public GitHub full-Setup asset counts, including repeat requests. Counts are independent of Google Analytics consent or email signup, may take a few minutes to refresh, and do not establish unique people, completed transfers or installations. Earlier Lemon Squeezy downloads are excluded. GitHub failures display unavailable rather than zero.

The homepage email form is optional and separate from download links. `newsletter.js` submits only after a visitor enters an address and presses Subscribe, using the existing API subdomain and a versioned consent record. The Worker allows signup CORS only for the two production website origins. No email/token is stored in browser storage or sent to analytics. Newsletter errors never block an installer download. With JavaScript disabled, the optional form provides an email contact; installer links still work.
