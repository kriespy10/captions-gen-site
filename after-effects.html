Before you download

Check your app and computer.

The current public release is for Windows. It does not include a Mac installer.

After Effects
After Effects has been tested with After Effects 2026 on Windows 11; earlier After Effects versions are not certified for this release. Creative Cloud Desktop and Adobe installation permissions are required.
Local processing
Meet Adobe's processor, RAM and GPU requirements for the Adobe application you use, with memory available for the speech model. Transcription uses the CPU, without GPU acceleration; a dedicated GPU is not required for transcription itself.
Speech models
Allow at least 3 GB free for the built-in speech models, in addition to the plugin, Adobe applications and project files. Both panels use the same engine and Models folder. Model sizes can change, and custom models need additional space. Base is the lightest built-in option; Small and the default Turbo are also available.
Internet and footage
Audio and video are not uploaded for transcription. The engine downloads missing speech models and caches them for later use. Model downloads, update checks and legacy license checks use the internet.
One Windows setup
Choose After Effects or Both. Both panels share the engine and Models folder. Installing the Premiere Pro panel is optional.

The Windows setup remains Authenticode-unsigned. The Adobe CEP package signature is separate and does not resolve a Windows Smart App Control block. If setup is blocked, contact support. See all current product facts and limits.

Questions before installing

A few useful details.

Is Captions Gen free for After Effects?

Yes. The current Windows plugin is free, with no watermark, subscription or transcription time cap. Download the installer directly without an email address or payment card. Newsletter signup is optional. Adobe After Effects is a separate paid application. Paid Captions Gen features are planned for the future.

Which After Effects and Windows versions are supported?

After Effects has been tested with After Effects 2026 on Windows 11; earlier After Effects versions are not certified for this release. This public release does not include a Mac installer. Meet Adobe's requirements for the installed application, with memory available for the speech model.

Does my audio or video leave my computer for transcription?

Audio and video are not uploaded for transcription. The engine downloads missing speech models and caches them for later use. Model downloads, update checks and legacy license checks use the internet.

Can I correct the captions and change their design?

Yes. Use the After Effects panel's Captions tab to correct text. Save caption updates the text and animation together. After a manual Source Text edit, use Update animation where offered and review word timing. Appearance-only Apply style changes reuse the existing timing; changing caption grouping can require transcription again.

Can Captions Gen import SRT or translate subtitles?

This public release creates animated caption layers from speech. It does not import SRT, convert native subtitle tracks or translate speech. The animation renders into the picture. Use a separate subtitle workflow when delivery requires an SRT file, selectable subtitles or broadcast captions.

Do I also need to install the Premiere Pro panel?

No. Choose After Effects in the Windows setup if that is the panel you need. You can choose Both to install the Premiere Pro panel too. The panels share one speech engine and Models folder; the Adobe applications are separate paid products.
