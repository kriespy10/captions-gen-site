After Effects captions not showing: find the failed step

Published 9 November 2026 · by Kris, maker of Captions Gen

After Effects guide. Free plugin, output examples and compatibility. Working in Premiere Pro? Choose a Premiere caption workflow.

When captions do not show in After Effects, first identify what is missing: the Captions Gen extension, a generated caption layer, or the captions in the exported file. Reinstalling the panel will not fix a layer excluded by Solo, and generating again will not fix an export that uses the wrong composition or time range.

This checklist covers Captions Gen's public 1.1.9 Windows release, tested with AE 2026 on Windows 11. It does not treat an SRT file as a generated Captions Gen layer. For the complete first-use procedure, follow the setup and first-captions guide.

The extension is missing from the menu

Look under Window > Extensions > Captions Gen. AE uses the released CEP panel; Premiere's Window > UXP Plugins instructions do not apply here.

If the entry is absent, save your work, close AE, and run the current full Windows Setup with After Effects or Both selected. Complete Adobe's installation prompts and reopen AE. A Premiere-only selection does not install the AE extension.

Earlier AE versions are not certified for this release, and there is no public Mac installer. Check the current compatibility requirements. Do not copy development debug-mode or registry instructions into a public installation. If Windows blocks the EXE, contact support rather than treating the Adobe package signature as a Windows signing fix.

The panel opens but no captions are created

CheckWhat to do
Engine offlineStart the installed Captions Gen engine from Windows Start, reopen the panel and check its status.

The panel reads source files. It does not record the rendered composition mix, and moving the work-area handles does not select the transcription input. Start with one short, unprocessed speech layer to separate source problems from project complexity. Read any displayed error before changing the setup.

Caption layers exist but the picture is blank

  1. Confirm the viewer and timeline belong to the parent composition where the batch was generated.
  2. Move the playhead inside a caption's start/end range. A caption layer need not show across the entire composition.
  3. Check the caption layer's Video switch, and review Solo on the source video and other visual layers.
  4. Check whether an opaque layer above the caption covers it. The panel's placement choice can put captions above the selected source or at the top of the composition.
  5. Check opacity, scale and position on the caption and relevant parent/nested layers if you changed them after generation.

Adobe explains that Solo can exclude other visual layers from both previews and rendering. It also distinguishes Shy from visibility: Shy can hide a row in the Timeline panel while the layer still renders. See Adobe's layer management reference.

If you cannot find a layer row, clear timeline search/filtering and review Hide Shy Layers. If the row exists but the output is absent, concentrate on its Video switch, Solo, time range and composition rather than Shy alone.

The layer is visible but the words or highlight look wrong

Check that the current time is inside the phrase rather than before its entrance or during its exit. Open the panel's Captions tab to confirm the stored wording. After a manual Source Text edit, select the generated caption in its parent composition and use Update animation when offered.

A successful Save caption through the panel already updates animation. It does not need that extra step. If added words have estimated timing, review them with sound. Follow the text and timing recovery guide before changing the generated rig itself.

Check the font, text color and background contrast too. A white caption over a bright shot can be technically present but hard to read. A different stroke or background can improve contrast; preview the exported result rather than judging the design on one still frame.

Captions appear in AE but are missing from the export

Check that the queued/exported composition is the parent composition containing both video and captions. Then check its render time span. Adobe's render settings distinguish the full composition from Work Area Only. Review that setting in the rendering and exporting reference, along with any layer-switch overrides you changed.

Render a short section containing a caption and watch the output file. If that works, use the same confirmed composition and settings for the intended range. A caption rendered into the picture will not become a selectable subtitle track or a separate SRT file.

What to include in a useful bug report

Record the AE version, Captions Gen version, exact error, model, source type and the step that failed. Say whether the caption layer was never created, exists but is invisible, or only disappears in export. A screenshot of the relevant timeline and panel can be useful, but remove client details before sharing it.

Choosing Send bug report attaches recent engine diagnostics. Messages and logs can include paths or filenames; see the report privacy details. Avoid sending a project or media file unless support actually needs it and you are authorized to share it.

Questions people ask

Where should the Captions Gen panel appear in After Effects?

The public Windows panel opens from Window > Extensions > Captions Gen. If it is missing, save work, close AE and run the current full Setup with After Effects or Both selected. Premiere's UXP Plugins menu is a different installation path.

Why is a caption missing after I solo the video?

Soloing a video layer can exclude other visual layers, including separate caption layers, from preview and render. Review the Solo switches as well as each caption layer's Video switch.

Does the Shy switch stop captions from rendering?

No. Shy hides a layer from the Timeline panel when Hide Shy Layers is enabled. It does not by itself remove the layer from preview or final output. Check Video visibility, Solo, time range and render settings instead.

Why does the work area not limit caption generation?

Captions Gen reads supported selected source layers and their visible ranges. The composition work area is not its transcription selector. Render time-span settings control a separate stage of output.
