Edit caption text and update timing in After Effects

Published 9 November 2026 · by Kris, maker of Captions Gen

After Effects guide. Free plugin, output examples and compatibility. Working in Premiere Pro? Choose a Premiere caption workflow.

To correct a Captions Gen caption in After Effects, open the panel's Captions tab, choose the caption, change its text and press Save caption. The save updates text and animation together. Use the separate Update animation action after a manual Source Text edit, when the panel offers it.

This guide covers the public 1.1.9 Windows panel. It assumes you already have generated captions. For installation and your first batch, start with adding captions in After Effects.

Correct a caption in the panel

  1. Open the composition containing the generated caption layers.
  2. Open Captions in the Captions Gen panel.
  3. Use Search captions to find the phrase. Check its text and start/end time so you edit the intended occurrence.
  4. Choose the caption's edit action, correct its words and press Save caption.
  5. Preview that phrase with the original audio and check the changed words.

The list belongs to the current composition. If the composition changes while an edit is open, choose the caption again in the current list rather than treating an old selection as current. An empty list can also mean the open composition has no compatible generated captions.

For example, changing we make caption to we make captions is a text correction. Adding clear animated creates new words that need timing. The editor can try local alignment when the original source binding is valid; it reports estimated timing when that route is unavailable. Neither outcome removes the need to listen.

Find and replace a repeated mistake

In Captions, open Find & replace. Enter the word or phrase under Find whole words, enter the replacement, review the affected captions and their preview text, then use Replace all. This feature is marked free during early access in the public panel.

Matching ignores letter case and uses whole words. Finding cat matches Cat, but does not replace part of category. Replacement text is literal. Leave the replacement empty to inspect matches; do not use that as a bulk-delete method.

Replace all updates text and timing for the changed captions. Use AE's Edit > Undo if the replacement was wrong, then check the restored wording and animation. A narrow replacement is easier to review than changing a short common word across a long composition.

Recover animation after a manual Source Text edit

Generated phrases are precompositions with editable text inside. Adobe documents Source Text as the text layer's content and formatting property. Changing that property directly can leave the generated word animation referring to its earlier text.

  1. Save the project, then open the generated caption precomposition and change the intended text.
  2. Return to the parent composition containing the generated caption layer.
  3. Select the changed caption layer.
  4. Use Update animation when the panel shows Caption text changed.
  5. Preview the full phrase, including the words before and after the edit.

If the action is absent, confirm you selected a compatible generated caption in the parent composition rather than an arbitrary text layer or an unrelated precomposition. Don't rebuild text animators or remove the generated rig to force the button to appear.

Check timing at the speech, not just the cut

The whole phrase can sit in the correct place while a newly inserted word highlights too early. Listen for the first changed word and check where its highlight begins. Also inspect the next unchanged word, because a phrase can sound right at the start and drift near its end.

Available timing anchors help preserve unchanged words. Added words may align to valid original audio or use estimated timing. A moved or retimed source, missing media or an unavailable binding can prevent audio alignment. If the speech has changed substantially, generate from the current supported source rather than expanding an old caption into unrelated dialogue.

Do not stretch or time-remap generated caption layers as a shortcut for repairing text. Return to a supported source workflow and check the result against speech. The word-by-word styling guide explains the difference between phrase grouping and timed highlights.

Change the look after the wording is correct

Use Presets or Customize, then Apply style for the current batch in the active composition. Font, color and design changes are different from transcript corrections. Grouping changes can regenerate captions from saved source history, so don't assume every Apply style operation is only a cosmetic change to one selected layer.

Save a version before a wide restyle. Keep a separate subtitle delivery workflow if the job also needs SRT or selectable captions; these editable AE layers still render into the picture. If the text is correct but the layer disappears, use the visibility troubleshooting checklist.

Questions people ask

Does Save caption update the animation automatically?

Yes. The Captions Gen editor saves the text and updates animation together. You do not need a second Update animation step after a successful save. Review newly added words because audio alignment can be unavailable and fallback timing can be estimated.

When should I use Update animation?

Use it when offered after manually changing Source Text inside a supported generated caption. Return to the parent composition and select that caption. This is different from saving through the panel's caption editor.

Can I replace a repeated word across a composition?

The AE Captions tab has whole-word, case-insensitive find and replace, with previews before Replace all. It works on the generated captions listed for the current composition. The public 1.1.9 panel marks this feature free during early access.

Does Apply style change the caption wording?

Use Apply style for the current batch's look. Use the caption editor or find/replace for text corrections. Grouping changes can regenerate captions, so check the result and keep a saved project before wider changes.
