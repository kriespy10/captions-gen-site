How to add animated captions in After Effects

Published 8 November 2026 · Updated 9 November 2026 · by Kris, maker of Captions Gen

After Effects guide. Free plugin, output examples and compatibility. Working in Premiere Pro? Choose a Premiere caption workflow.

To add animated captions in After Effects with Captions Gen, install its Windows panel, select a supported audio or video layer, choose a look and press Generate Captions. The panel transcribes the selected speech locally and places editable caption layers in your composition. The animation becomes part of the video image when you render it.

I make Captions Gen. These instructions cover the public 1.1.9 release, tested with After Effects 2026 on Windows 11.

Before your first caption

  • Use After Effects 2026 on Windows 11 for the tested public configuration.
  • Install After Effects or Both from the full Windows Setup.
  • Allow at least 3 GB for the built-in models, plus your apps and project files.
  • Start with one short, online media layer at normal speed with audio enabled.
  • Wait for the engine and your chosen model before generating.

1. Install and open the After Effects panel

  1. Save your projects and close the Adobe applications.
  2. Download the current Windows Setup. The installer downloads directly; no email address or payment card is required.
  3. Run Setup and choose After Effects, or Both to install the Premiere Pro panel too. Keep Creative Cloud Desktop installed and complete Adobe's installation prompts.
  4. Open After Effects, then choose Window > Extensions > Captions Gen.

A Premiere-only installation does not add the AE panel. Run the full Setup with Both selected when you want to add it. The two panels share the speech engine and Models folder.

The current plugin is free, without a watermark, subscription or transcription time cap. Adobe After Effects is separate and paid. Paid plugin features are planned for the future. Check the current pricing and compatibility facts before downloading.

If Windows blocks the EXE, contact support. The Windows EXE is Authenticode-unsigned; the signed Adobe panel package does not resolve a Windows Smart App Control block. Development instructions for CEP debug mode are not public installation steps.

2. Choose a model and spoken language

Let missing model downloads complete. In Settings, choose Base, Small or Turbo. Turbo is the default quality choice; Base is the lightest built-in model. Processing time depends on your CPU, the model and audio length, so start with a short section you can check.

Use Spoken language for the language actually being spoken, or Auto-detect. Search the picker by language name or code. Cantonese requires Turbo or a compatible custom model. The Custom models manager lets you refresh compatible Faster Whisper folders in the shared Models directory and assign a model to a language. It does not make an incompatible model support a language.

Transcription uses your CPU without GPU acceleration. Meet Adobe's After Effects requirements as well, with memory available for the model. Allow at least 3 GB free for the built-in models in addition to the plugin, Adobe apps and project files.

The speech engine reads audio locally. Missing models and update checks need the internet. Optional usage statistics and reports you choose to send are separate from transcription; see the privacy details. Language selection does not translate captions.

3. Select the source and check its range

Open the composition where you want the captions. Select one short, file-based audio or video layer with clear speech and audio enabled. Multiple supported selected layers can be used later, but the panel reads their source files rather than recording the rendered composition mix.

Keep the source online and at 100% forward speed, with Time Remapping off. Stretching, reversing or an unsupported interpreted frame-rate change can make it unsuitable. If the speech depends on retiming or After Effects audio effects, render that version to a new file and use the rendered file as the source.

The panel clips the selected layer's visible in/out range to the composition and source bounds. To caption less of a long source, prepare a shorter source-layer range and test it. The work area matters separately when you choose a render range.

4. Pick a look and generate your first captions

  1. Choose one of the 18 built-in looks in Presets.
  2. Open Customize if you want to change the font, colors, grouping or animation before generation.
  3. In Settings, choose whether caption layers go above the selected layer or at the top of the composition.
  4. Enable Check transcript before generating if you want a text review first.
  5. Press Generate Captions. Complete the transcript review if offered, and keep the composition and selected source unchanged until placement finishes.

The result is a set of editable caption precomposition layers. Play them with the original speech and check names, numbers, phrase breaks and highlight timing. A different preset changes the design, not whether the transcript needs proofreading.

For a single word on screen at a time, use the one-word layout instructions. For a phrase that stays visible while its spoken word changes color, use a karaoke highlight. Those are separate design choices.

The interactive browser demo has an After Effects mode with prepared sample captions. It demonstrates design and editing concepts without transcribing your media or operating your Adobe project.

5. Correct the transcript and restyle the batch

Open Captions, search for a phrase, choose it, edit the text and use Save caption. Saving updates its animation too. A valid original-audio link lets the panel try aligning added words; if that is unavailable, it can report estimated timing. Listen again after the correction.

If you edit Source Text manually inside a generated caption instead, return to the parent composition, select the changed caption and use Update animation when offered. You do not need this extra action after a successful Save caption. The editing and timing guide covers both paths and find/replace.

Change the current look and use Apply style to restyle the current batch. Design-only changes do not need another transcription; changes to grouping can regenerate captions using source history. Save the project before wide changes, and use AE's Edit > Undo when you need to undo a supported grouped edit.

6. Render and inspect a short output file

Render a short part of the composition before committing to a long export. Adobe documents Composition > Add to Render Queue, then choosing render/output settings, an output destination and Render. Check whether the render time span is the full composition or Work Area Only. See Adobe's rendering and exporting guide.

Watch the actual file with sound. Check that the caption layers are visible, the text is readable over the footage, and important words do not sit under the destination platform's interface.

The animation renders into the picture. This workflow does not export SRT, native subtitle tracks or selectable closed captions. If those are part of your delivery, prepare them separately. Premiere users can follow the native SRT workflow.

If setup or the result looks wrong

A missing extension, an offline speech engine and an invisible generated layer need different fixes. Use the After Effects captions troubleshooting guide to identify which stage failed before reinstalling or generating again.

This public release does not include a Mac installer, translation or automatic B-roll. When reporting a problem, include the AE version, panel version, exact error and the step that failed. Choosing to send a bug report also attaches recent engine diagnostics, as explained on the privacy page.

Questions people ask

Is Captions Gen free for After Effects?

The current Windows release is free, without a watermark, subscription or transcription time cap. The installer downloads directly without an email address or payment card. Adobe After Effects is a separate paid application. Paid Captions Gen features are planned for the future.

Which After Effects versions are supported?

The public panel has been tested with After Effects 2026 on Windows 11. Earlier After Effects versions are not certified for this release. There is no public Mac installer.

Does the work area choose which audio is transcribed?

No. Captions Gen reads the underlying media files of the selected supported layers, using their visible ranges within the composition. The work area does not choose the transcription range. Render a processed or retimed source to a new file when that is what you need captioned.

Do I need to run Update animation after Save caption?

No. Saving through the panel's caption editor updates text and animation together. Update animation is the separate path offered after a supported manual Source Text change. Newly added word timings still need checking against the original speech.

Can this After Effects workflow export SRT or selectable subtitles?

No. It creates editable animated caption layers that render into the picture. Keep a separate subtitle workflow when delivery needs SRT files, selectable subtitles or broadcast closed captions.
