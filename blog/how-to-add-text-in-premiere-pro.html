How to add text in Premiere Pro

Published 26 August 2026 · Updated 9 November 2026 · by Kris, maker of Captions Gen

Premiere Pro guide. Using After Effects? Install its panel and create your first captions.

Select the Type tool, click in Premiere Pro's Program Monitor and type your title. The result is a graphic in the sequence. Select it to adjust text and appearance in Properties, then set its duration on the timeline. For speech subtitles or SRT delivery, use a native caption track instead.

Choose a title, subtitle or animated speech graphic

A name label, lower third or chapter heading can be a text graphic without transcription. Dialogue that needs selectable subtitles belongs in a caption workflow. A designed, animated speech treatment can use graphics, but the delivered picture alone does not supply a subtitle file.

Knowing which you need prevents a long edit full of manually typed titles when a transcript-to-caption workflow would be more suitable.

Create the text graphic

  1. Open the intended sequence and place the playhead near the title's start.
  2. Select the Type tool from the toolbar. With the standard keyboard layout, T is its shortcut; custom shortcuts can differ.
  3. Click in the Program Monitor and enter the wording. Check spelling before duplicating the title across several shots.
  4. Select the graphic on the timeline and inspect its start and end. Drag its edges to cover the required part of the edit.
  5. Preview the title with the underlying footage and audio, rather than judging only the text in isolation.

Adobe's current instructions use the Properties panel. If an older tutorial sends you to Essential Graphics for editing text, look for the equivalent text and appearance controls in Properties in your installed version.

Style a title or lower third

With the intended text layer selected, choose its font, weight, size and fill. Add a stroke or background when the footage makes the words hard to see. Check the longest name or line you expect to use, including accented characters.

Use alignment controls for deliberate placement and leave room for the destination's player interface. A lower third should not cover an important face, demonstration or existing subtitle. For a vertical crop, review the graphic after reframing.

To reuse a design, save an appropriate text style or duplicate a correctly prepared title and replace its wording. For native subtitles, the corresponding reuse mechanism is a Track Style; the two jobs should remain identifiable.

Animate a simple fade

Start with a short title before building a complex animation. Select the graphic, open Effect Controls and locate the opacity property for the item or layer you intend to animate. Set the playhead at the desired start and enable its stopwatch.

Set opacity to zero at the first keyframe, move forward and set it to full visibility. Preview the change, then add an exit later if needed. Check which level you animated: changing a whole graphic can affect every layer inside it. Use the relevant layer controls when only one part should move.

For position or scale animation, use the same keyframe process and review the complete title at normal speed. Adobe also provides keyframe interpolation controls. A fast entrance should still leave enough time to read the words.

If the text is missing or uneditable

Confirm that the playhead is inside the graphic's duration and its video track is enabled. Check for an opaque clip above it, off-frame placement, zero opacity or an unexpected animation keyframe.

If typing creates another title, select the intended graphic and text layer before editing. If a font is substituted, install or activate the required family and weight, then check line breaks again. See the font troubleshooting guide for related checks.

For text that follows speech

Premiere's native Single Word layout can show a timed word at a time. For a moving highlight across a phrase, use timed graphics or a plugin such as Captions Gen. The current Windows plugin transcribes locally on the CPU and creates editable graphics; it does not convert those graphics into a native subtitle file.

For a composition-based version, follow the After Effects caption guide. For either app, render a short final-size sample and check the actual file before applying the design throughout the project.
