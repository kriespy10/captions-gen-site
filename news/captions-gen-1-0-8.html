Captions Gen 1.0.7 and 1.0.8: start the engine from the panel

v1.0.87 October 2026 · by Kris, maker of Captions Gen

Captions Gen runs a small engine on your computer for transcription and previews. It starts with Windows, but Windows can switch that off (Task Manager › Startup apps). When that happened, the panel said Caption engine is offline and the only way back was the Start menu.

The offline card now has a Start engine button. Press it, allow it if Premiere asks, and the panel picks the engine up within a few seconds.

1.0.8 is the same change. It was republished with a new version number because Creative Cloud skips installing a panel whose version hasn't changed.

Get the update

Already using Captions Gen? Open the panel in Premiere Pro and press Update when it shows, then restart Premiere Pro. New here? Captions Gen is free, with no time limit.
